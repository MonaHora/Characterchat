# CharacterChat APK

1. Upload everything in this folder to a GitHub repo (keep the .github folder).
2. Actions tab -> "Build APK" -> Run workflow.
3. Download "CharacterChat-apk" from the run's Artifacts and unzip it for app-debug.apk.
4. Install it on your phone (allow "install unknown apps").
5. In the app tap the gear, paste your Anthropic API key, and chat.
